# 血压用药预警系统 (BP Medication Alert System)

基于气温预报和药代动力学(PK)的高血压用药推荐与预警系统。

## 核心思路

气温与血压呈负相关：温度每降10°C，收缩压升高约3-5 mmHg。寒冷引起血管收缩是**数小时内**发生的，但降压药（诺欣妥/沙库巴曲缬沙坦）需要**2-3天**才能达到新的稳态血药浓度。

**关键矛盾**：血压升得快，药物跟得慢。

### PK修正模型

本系统的核心创新是区分了加药和减药的**不对称性**：

| 方向 | 血药浓度变化 | 安全性 | 策略 |
|------|-------------|--------|------|
| 加药（半颗→1颗） | 需2-3天达新稳态 | 有2天"保护真空" | **提前1-2天预加载** |
| 减药（1颗→半颗） | 药物残留2-3天缓冲 | 安全 | 可按趋势逐步减 |
| 停药（半颗→停药） | 残留率25%→6%→1.5% | 安全 | 可直接停 |

### 迟滞规则 (Hysteresis)

防止剂量频繁波动：

- **停药阈值**：3日滑动均温(T3d) ≥ 25°C 持续3天以上
- **重新用药阈值**：T3d < 20°C（而非25°C）
- 20-25°C 之间为"维持当前剂量"缓冲区

## 药代动力学参数

```
药物：诺欣妥 (沙库巴曲缬沙坦钠片) 200mg
活性代谢物 LBQ657 半衰期：11.5 小时
缬沙坦半衰期：9.9 小时
日残留率：23.5%（24小时后血药浓度残留比例）
蓄积比：~1.3（每日一次给药）
达稳态时间：~3 天
```

## 脚本说明

| 脚本 | 功能 |
|------|------|
| `merge_bp_temp.py` | 合并血压CSV和气温CSV，填充无测量日数据 |
| `analyze_bp_temp.py` | 血压-气温相关性分析（Pearson r、温度分层、季节差异） |
| `medication_alert.py` | 药物等效剂量分析 + 简单温度模型用药推荐 |
| `pk_refined_model.py` | PK药代动力学模拟，加药/减药不对称性分析 |
| `pk_alert_engine.py` | **核心引擎**：PK感知的每日用药推荐与预警 |

## 数据流

```
血压记录.csv ─┐
              ├── merge_bp_temp.py ── 血压气温合并.csv
西安气温数据.csv ┘                      │
                                       ├── analyze_bp_temp.py (统计分析)
                                       ├── medication_alert.py (基础推荐)
                                       └── pk_alert_engine.py (PK修正推荐)
```

## 用药推荐框架

```
IF 预报未来2-3天 T3d 将降至 < 15°C:
   → 立即加至 1颗（不等温度真的降下来）

IF 当前 T3d < 15°C:
   → 维持 1颗

IF 当前 T3d 15~25°C:
   → 维持当前剂量（迟滞缓冲）

IF T3d ≥ 25°C 持续3天 AND 无降温预报:
   → 可停药（PK残留保护）
```

## 预警级别

| 级别 | 触发条件 | 行动 |
|------|---------|------|
| 🟡 黄色 | 24h降温 ≥ 5°C | 考虑提前加药 |
| 🟠 橙色 | 最高温 < 10°C | 加至1颗，增加测压 |
| 🔴 红色 | 最高温 < 5°C 且最低温 < 0°C | 1颗 + 注意保暖 |

## 定时任务

每日 20:30 自动执行：
1. 获取西安未央7天天气预报
2. 读取最近实际气温和血压
3. 运行PK引擎生成逐日推荐
4. 有预警立即推送
